# Dhaka Dash

Satirical 3D street brawler: ordinary people versus corruption on a Dhaka avenue. Built with Three.js.

## Run

```bash
npm install
npm run build
```

Open `index.html` in a browser (or serve the folder with any static server).

## Develop

```bash
npm run watch
```

## Stack

- Three.js
- esbuild
- html-to-image
